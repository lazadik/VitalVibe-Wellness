## 🌿 About The Project

**VitalVibe Wellness** is a modern, high-performance e-commerce platform dedicated to premium botanical supplements. Built with a focus on brand storytelling and conversion, it features a custom **"Botanical Protocol Guide"** that personalizes recommendations based on user goals (Sleep, Energy, Focus, etc.) using a local keyword-matching engine.

The design emphasizes purity, clinical precision, and natural aesthetics using a sophisticated color palette, glassmorphism effects, and fluid page transitions.

---

## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| **🧠 Smart Recommendations** | A custom logic engine that maps user input to specific botanical compounds and products. |
| **🛍️ Dynamic Cart** | Fully functional shopping drawer with persistent storage and a real-time "Free Shipping" tracker. |
| **🔍 Instant Search** | Client-side filtering allowing users to find products by name, category, or benefit instantly. |
| **🎨 Aesthetic Design** | Immersive UI with blur-backdrops, smooth hash-based routing, and responsive animations. |
| **📱 Mobile Optimized** | Touch-friendly interfaces and adaptive layouts for a seamless experience on any device. |

---

## 🛠️ Technology Stack

*   **Frontend Library:** React 19
*   **Language:** TypeScript
*   **Styling:** Tailwind CSS (Runtime/CDN for zero-config deployment)
*   **Icons:** Google Material Symbols
*   **Build/Runtime:** Babel Standalone (Optimized for Vercel static hosting)

## 🚀 Getting Started

You can run this project locally to explore the code or customize the design.

### Prerequisites

*   Node.js (optional, for package management)
*   A modern web browser

### Installation

1.  **Clone the repo**
    ```bash
    git clone https://github.com/lazadik/VitalVibe-Wellness.git
    ```

2.  **Navigate to the directory**
    ```bash
    cd VitalVibe-Wellness
    ```

3.  **Run the application**
    *   **Option A (Fastest):** Open `index.html` directly in your browser.
    *   **Option B (Recommended):** Use the "Live Server" extension in VS Code.
